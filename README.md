# tauseefahmad.github.io

Personal portfolio of Tauseef Ahmad Awan, served with GitHub Pages at
https://tauseefahmad.github.io.

Plain HTML, CSS and JavaScript: no framework, no build step, no cookies, no tracking,
and no third-party requests (system fonts only).

- `index.html`: content
- `styles.css`: design tokens, light/dark theme, layout
- `main.js`: theme toggle, scroll reveal, avatar tilt, terminal replay, and a browser port of the
  FAIR checks from [fair-data-catalog](https://github.com/tauseefahmad/fair-data-catalog)

Run locally:

```bash
python -m http.server 8090
```
