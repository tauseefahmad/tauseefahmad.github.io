    Data engineering · Python ETL

    Order Data Pipeline

    An ETL pipeline for e-commerce order exports that rejects bad rows instead of guessing, explains every rejection, and can be re-run safely because loads upsert on the natural key.

    • pydantic validation with readable reasons per row and file line number
    • E-mails pseudonymised with SHA-256 (GDPR data minimisation)
    • Money in Decimal with half-up rounding, never floats
    • Same test suite on SQLite and PostgreSQL 16, Python 3.11–3.13
